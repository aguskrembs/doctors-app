# Exploraciones

Ideas de producto en análisis. Una exploración no compromete nada: sirve para entender el problema, abrir opciones y anotar lo que falta saber antes de decidir.

## Cómo se usa

1. Copiá [_plantilla.md](_plantilla.md) como `titulo-corto.md`.
2. Agregala a la tabla de abajo con estado **Abierta**.
3. Cuando haya una decisión, registrala en [../decisiones/](../decisiones/) y marcá la exploración como **Decidida → P-NNN**. Si se abandona, marcala **Descartada** con una línea de por qué.
